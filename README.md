# Full Stack Open – Exercises (Parts 0–6)

This repository contains my solutions and exercises for the **Full Stack Open** course by the University of Helsinki.

The course focuses on modern web development using JavaScript. The main technologies include React for the frontend and Node.js with Express for the backend.

Repository structure follows the course parts.
